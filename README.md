# 💅 NailLab

A modern e-commerce website for a professional nail salon and beauty brand.

The project was created to practice building and customizing a real-world online store, with a focus on responsive design, user experience, product presentation, and e-commerce functionality.

## 🔗 Live Website

[Visit NailLab](https://nailslab.cz/)

## 📦 Repository

[View Source Code](https://github.com/AleksandraCherevko/naillab-theme)

## 📌 About the Project

NailLab is an online store focused on professional nail care products and equipment.

The website allows customers to browse products, explore categories, view product details, and make purchases through an online shopping experience.

The project combines e-commerce functionality with a clean, modern visual design tailored to the beauty industry.

## ✨ Features

* Responsive e-commerce interface
* Product catalog
* Product categories
* Product search
* Product detail pages
* Shopping cart
* Checkout functionality
* Customer account functionality
* Responsive navigation
* Mobile-friendly interface
* Product images and detailed information

## 🎨 Design & UI

The website was designed with a focus on a clean and modern aesthetic suitable for a professional beauty brand.

* Consistent typography
* Responsive layouts
* Intuitive navigation
* Strong product presentation
